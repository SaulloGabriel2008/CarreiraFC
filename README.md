# ⚽ Carreira FC - Simulador de Carreira Rápido

> Um simulador de carreira futebolística ágil, viciante e minimalista para navegador. Crie seu atleta, jogue temporadas completas em segundos, supere dilemas de campo e extracampo, e construa seu legado eterno nos gramados.

## 🎯 Pilares Centrais
1. **Velocidade & Retenção (Inspirado no Copero)**:
   - Temporadas simuladas em poucos cliques com estatísticas instantâneas (jogos, gols, assistências, notas, títulos).
   - Tela final de aposentadoria com infográfico e pôster de lenda gerado em Canvas para download e compartilhamento social.
2. **Dilemas & Identidade Brasileira (Inspirado no 7 a 0)**:
   - Interface minimalista com tema *Dark Pitch Stadium*.
   - Decisões binárias e de múltipla escolha com consequências imediatas em atributos, finanças, moral e risco de lesões.

---

## 🛠️ Arquitetura Técnica
- **100% Client-Side**: Sem frameworks pesados ou processos complexos de build para rodar.
- **Vanilla ES6 Modules**: Código modular, limpo e orientado a objetos.
- **CSS3 Moderno**: Custom Properties (CSS Variables), Mobile-First, Flexbox e CSS Grid.
- **Persistência**: LocalStorage nativo com fallback.

---

## 🚀 Como Executar Localmente
Basta clonar o repositório e abrir o arquivo `index.html` em qualquer navegador web moderno:

```bash
# Clonar o repositório
git clone https://github.com/SaulloGabriel2008/CarreiraFC.git

# Entrar na pasta
cd CarreiraFC

# Executar com servidor estático (opcional)
npx serve .
```
